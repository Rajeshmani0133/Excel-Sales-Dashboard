# Excel Sales Dashboard | Microsoft Excel

## Project Overview
This project uses Microsoft Excel to analyze sales performance and present important business metrics through an interactive sales dashboard. It helps users explore sales, profit, product performance, regional performance, and salesperson results based on the available dataset.

## Objectives
- Analyze overall sales and profit.
- Compare product performance.
- Identify high-performing regions.
- Evaluate salesperson performance.
- Summarize business performance using charts and KPIs.

## Tools & Technologies
- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Excel Formulas
- Data Cleaning
- Data Visualization

## Dashboard Features
- Sales and profit KPI cards.
- Product-wise sales analysis.
- Region-wise performance comparisons.
- Salesperson performance analysis.
- Units sold analysis.
- Interactive filtering using slicers.

## Key Skills Demonstrated
- Data cleaning and preparation
- PivotTable creation
- PivotChart development
- KPI tracking
- Interactive dashboard design
- Sales and profit analysis

## How to View the Project
1. Download the `Excel Sales Dashboard.xlsx` file.
2. Open it using Microsoft Excel.
3. Navigate to the dashboard worksheet.
4. Use the available slicers and filters to explore sales performance.

## Files Included
- `Excel Sales Dashboard.xlsx` — Excel workbook and dashboard
- `README.md` — Project documentation

## Conclusion
This project demonstrates how Microsoft Excel can be used to analyze sales data, summarize business performance, and create interactive dashboards for reporting and decision-making.
